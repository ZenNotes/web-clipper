ZenNotes Web Clipper

Clip web pages, selections and highlights into ZenNotes as Markdown notes.

The extension is on in Safari.

The extension is off in Safari.

  1. Open Safari Settings, then Extensions.
  2. Turn on ZenNotes Web Clipper.
  3. Allow it on the sites you clip, or on every website.

Then press OptionShiftZ on any page to clip it.

Clips go to the ZenNotes app on this Mac. If it does not open, the note is on your clipboard, ready to paste.

  1. Open Settings, then Apps, Safari, Extensions.
  2. Turn on ZenNotes Web Clipper and allow it on all websites.

Or in Safari, tap the puzzle icon in the address bar, then Manage Extensions.

To clip a page, tap the puzzle icon, then ZenNotes Web Clipper.

Each clip is copied, ready to paste into a note in ZenNotes.

No account, nothing tracked.
