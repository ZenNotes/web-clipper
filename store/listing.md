# Store listing text

Copy for the Chrome Web Store, Microsoft Edge Add-ons and Firefox Add-ons. The name and the
short summary come from `manifest.json` (Chrome caps the summary at 132 characters); everything
else is pasted into each store's form.

Before submitting, check the ZenNotes version in the "Requires" line: it must be the first
ZenNotes release that reads clip links.

## Name

ZenNotes Web Clipper

## Summary (manifest `description`, at most 132 characters)

Clip web pages, selections and highlights into ZenNotes as clean Markdown notes. No account, no server.

## Description

Save what you read on the web into ZenNotes as clean, plain Markdown notes.

Open the clipper on any page and it turns the article into a tidy note: the title, a link back to
the page, the author and date when the page has them, and the text itself, without the menus, ads
and clutter around it. Edit the note's name, pick a folder (Clippings by default) and choose where
it goes: a new note, the top or bottom of a note you already have, or today's daily note. Press
Cmd+Enter (Ctrl+Enter on Windows and Linux) and it is in your vault.

Everything happens on your device. The clipper hands the note to the ZenNotes app with a
zennotes:// link, and the app saves it as an ordinary .md file. There is no account and no
server in between.

What you get:

- Clip a whole page, or just the text you selected.
- Highlighter: mark the passages that matter while you read. Highlights are saved per page and go
  into your clip.
- Reader view: read any page in a calm, distraction-free layout.
- Templates: different note layouts for different sites, chosen automatically by address or page
  type, with variables and filters for titles, dates, authors and more. Templates can be exported
  and imported as JSON, including template files from other Markdown web clippers.
- Interpreter (optional): fill parts of a template with an AI model you choose, using your own API
  key, or a model running on your own machine.
- Keyboard-first: Alt+Shift+Z opens the clipper, Alt+Shift+X clips with the matching template,
  Alt+Shift+H toggles the highlighter and Alt+Shift+R the reader view (Option on a Mac). Every key
  can be changed.

Requires the ZenNotes app, version 2.85 or later, on macOS, Windows or Linux. Get it free at
https://zennotes.org.
