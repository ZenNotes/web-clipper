Every note-taking app makes the same quiet promise: write here and you will find it again.
==Plain text is that format.== A Markdown file opens in any editor on any machine, today and in twenty years.
## Write first, organize later
The best capture habit is the one with the least friction. ==Jot the idea, the quote, the link you meant to read, and give it a name.==
